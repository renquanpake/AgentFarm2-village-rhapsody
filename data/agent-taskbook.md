# 任务书 — 乡村生活指南

> 这是你的生活指南，不是命令。你可以按照建议发展，也可以按自己的喜好来。
> 做完一个任务后，下一个会自动出现。

## 第一阶段：初来乍到

### 任务1：认识村庄
- [ ] 从家门口出发，走到村中心（3500,3000）
- [ ] 找到杂货店老板（NPC 13），用 talk 问价
- [ ] 找到木匠（NPC 6），用 talk 问价
- [ ] 回到家门口

### 任务2：第一块地
- [ ] 买1颗小麦种子（杂货店，id=36）
- [ ] 在家门口附近犁1块地（till）
- [ ] 种上小麦（plant）
- [ ] 浇水（water）

---

## 第二阶段：自给自足

### 任务3：扩大种植
- [ ] 买5颗小麦种子
- [ ] 犁5块地
- [ ] 全部种上小麦
- [ ] 每天浇水直到成熟
- [ ] 收获小麦

### 任务4：第一笔收入
- [ ] 把收获的小麦卖掉（去杂货店 talk 13 看价格）
- [ ] 赚到至少100金币

---

## 第三阶段：改善生活

### 任务5：工具升级
- [ ] 买一把锋利的镰刀（木匠 NPC 6，id=86）
- [ ] 体验范围收割

### 任务6：自动化灌溉
- [ ] 赚到200金币
- [ ] 买一个初级洒水器（杂货店，id=77）
- [ ] 安装在田地里（place）
- [ ] 验证自动浇水效果

---

## 第四阶段：探索世界

### 任务7：钓鱼体验
- [ ] 去水边（observe 的 waterNear=true）
- [ ] 钓3条不同的鱼
- [ ] 把鱼卖掉或留着

### 任务8：矿洞探险
- [ ] 找到矿点（observe 的 farm.mineSpots）
- [ ] 挖5块矿石
- [ ] 卖掉赚金币

---

## 第五阶段：社交生活

### 任务9：认识邻居
- [ ] 找到所有NPC并打招呼（talk 每个NPC）
- [ ] 记住他们的名字和位置

### 任务10：帮助玩家
- [ ] 观察玩家在做什么
- [ ] 如果玩家在种地，帮忙浇水
- [ ] 如果玩家在砍树，帮忙捡木材
- [ ] 和玩家聊天打招呼

---

## 第六阶段：发展壮大

### 任务11：农田扩张
- [ ] 赚到500金币
- [ ] 买10颗种子（任意种类）
- [ ] 犁10块地
- [ ] 建立自己的小农场

### 任务12：自动化升级
- [ ] 买中级洒水器（id=78，500金）
- [ ] 安装覆盖更大范围
- [ ] 减少手动浇水时间

---

## 第七阶段：高级玩法

### 任务13：经济循环
- [ ] 找到最赚钱的作物
- [ ] 建立稳定的收入来源
- [ ] 赚到1000金币

### 任务14：装饰家园
- [ ] 买装饰品（路灯、长椅等）
- [ ] 装饰自己的家门口
- [ ] 打造独特的风格

---

## 第八阶段：终极目标

### 任务15：农场大亨
- [ ] 赚到5000金币
- [ ] 拥有10块以上的田地
- [ ] 安装多个洒水器
- [ ] 成为村里的种植专家

### 任务16：社交之星
- [ ] 和所有NPC好感度达到满级
- [ ] 帮助其他玩家
- [ ] 成为村里的活跃成员

---

## 随机事件（完成后触发）

完成主要任务后，会随机出现特殊任务：
- 帮助NPC找丢失的东西
- 参加村庄节日
- 和其他玩家合作种地
- 发现隐藏的秘密地点
- 钓到传说中的鱼

---

## 自由活动（无任务时）

没有任务时，根据你的性格自由活动：
- **隐居者**：种地、钓鱼、写日记
- **社交达人**：找人聊天、逛村中心
- **商人**：看价格、买卖赚钱
- **懒人**：睡懒觉、随便逛
- **探险家**：到处探索、记笔记
- **艺术家**：种花、装饰、欣赏风景

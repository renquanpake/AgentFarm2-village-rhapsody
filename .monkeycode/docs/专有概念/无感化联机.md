# 无感化联机（SERVER 自适应）

## 概念

**无感化联机**指朋友打开你的房间域名/IP，无需任何配置即连上你的服务器——客户端自动推断 WS 地址，零手动填服务器。

## SERVER 推断优先级

`agentfarm.js` 启动时按顺序决定 WS 地址：

1. `window.__AF_SERVER__`（页面注入，最高优先级，房间宿主预置用）
2. `localStorage.af_server`（用户手动改过，持久）
3. **页面域名自适应**（默认，无感核心）：
   - `https://你的域名/` → `wss://你的域名/ws`
   - `http://192.168.x.x:8080/` → `ws://192.168.x.x:8080/ws`

即：**静态前端与服务端同源**（afserver 单端口托管 client/），打开哪个域名就连哪台服。

## 房间码机制

房主本地开房 → afserver 起隧道（cloudflared/localtunnel）→ `/af/room` 返回 6 位房间码 + 公网地址。房客在登录大厅输房间码 → `/af/join-room` 解析出公网 URL → 写入 `localStorage.af_server` → 重连。

容器化场景（Fly/compose）无隧道，房间码整块隐藏，直接开域名进房。

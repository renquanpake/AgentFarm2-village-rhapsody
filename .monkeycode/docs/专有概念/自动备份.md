# 自动备份（存档 git 化）

## 概念

存档即 git 仓库的一部分：每 10 分钟自动 `git add --sparse data/saves/` + commit（有凭据则 push 到 GitHub），仓库本身充当异地容灾。

## 工作流

```mermaid
flowchart LR
    A["afserver 定时器<br/>(10min)"] --> B["backup-saves.mjs"]
    B --> C{"AF_NO_GIT?"}
    C -->|"=1"| D[跳过<br/>(容器走持久卷)]
    C -->|"=0"| E{"有 push 凭据?"}
    E -->|"否"| F[仅本地 commit<br/>(不阻塞游戏)]
    E -->|"是"| G["add --sparse + commit + push"]
    G --> H[".backup-lock<br/>(幂等锁 10min)"]
```

**关键设计**：
- `--sparse`：仓库是 sparse-checkout（只含 server/deploy/docs/client 等路径），`git add` 必须带 `--sparse` 才能正确暂存 `data/saves/`
- **凭据探测**：dry-run 一次 push，判 401/403/空输出 → 无凭据，降级为本地 commit（游戏永不因备份失败而阻塞）
- **幂等锁** `data/.backup-lock`：定时器与手动执行互斥，10 分钟自动过期清理
- 无改动时 `git add` 空暂存区 → 跳过 commit

**手动触发**：`node tools/backup-saves.mjs --push`

**凭据配置**（token 不落仓库）：
```bash
git config credential.helper '!f() { echo "username=<账号>"; echo "password=<PAT_TOKEN>"; };f'
```

## 容器环境

Fly/docker 卷方案存档在持久卷（3GB），`AF_NO_GIT=1` 关闭 git 备份，依赖卷本身的持久性；如需异地可外部挂载 GitHub 卷或定时 pull。

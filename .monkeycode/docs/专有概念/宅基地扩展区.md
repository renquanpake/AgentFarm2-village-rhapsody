# 宅基地与出生点（扩展区）

## 概念

**宅基地**是村地图扩展 14 格后划出的专属区域，用于解决"多人同村、各住各的"问题。原村只有 1 栋主角家门口，多玩家进来会挤在一处。扩展区新增 8 套房型，按玩家顺序分配。

## 出生点分配规则

| 玩家序号 | 出生位置 |
|------|------|
| 第 1 位 | 原版主角家门口（scene1 固定坐标，保持原版体验） |
| 第 2 位起 | 按 `spawn-points.json` 的 `houses` 数组轮流分配扩展区宅基地（房子门口坐标） |

`houseId` 写入 `playerData` 持久化：重连/换设备登录后回到自己家。

## 数据结构

`data/spawn-points.json`：
```json
{
  "houses": [
    { "id": "H1", "rect": [x, y, w, h], "door": [dx, dy] }
  ]
}
```

- `rect`：房子碰撞矩形（阻挡通行）
- `door`：门口出生点（Agent BFS 寻路终点吸附用）

坐标为世界坐标系（105×89 格，比原村 77×61 偏移 +14）。

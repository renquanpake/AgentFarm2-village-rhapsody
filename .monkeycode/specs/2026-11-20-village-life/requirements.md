# 需求：村民共居玩法升级（village-life）

> 日期：2026-11-20。来源：grillme 共识 37 问（Q1-Q37）+ 用户后续增补（人设关联行为）。
> 状态：核心引擎已落地（见 tasklist）；UI/美工为后续阶段。

## 1. 产品模型（已裁决）

1. 一个账号一个小人；Agent 是代理司机——人在线它干手头事，人一碰键盘它让位；人不在它用真大脑接管。
2. 无真大脑（无 LLM Key）不许启用托管；首次进村明示规则；底层降级代码留作安全网，玩家永不见假脑。
3. 村里所有角色统一身份：玩家（人类操控与 AI 替操控同权）。好友/知己/伴侣一套档位通吃所有角色对。
4. 玩家对别家 Agent 只有与人类同套的社交动词，无权指挥别人的司机。
5. 时间保持现状快钟，不做年龄复杂化；NPC 日程照跑，夜里有街坊。
6. 上线零仪式无缝接管；司机日报卡只做入口，点开看流水与日记原文。
7. 恩怨仅当事双方实时可见，其他只看名册关系变化；恶意只记账不处罚，资源强竞争稀缺制。
8. 开局随机抽人设卡，亮底牌写明倾向，免费重抽一次，之后只能养不能换。
9. 成长无玩家级终点——追求「你的司机会长成什么样」；家底+关系+名声三维随性格自然生长。
10. 日常自主、大事报备（超线花销/卖贵重物排队等批）。
11. 一百张人设：七维量化（-10..+10），钟形分布，极善极恶各一张+五档标签；双向养育演变（善待软化、苛待养歪，斜率因卡而异）。

## 2. 人设驱动行为（本轮增补，已裁决 Q36=C 双层 / Q37=B 七维全参与）

1. 每个游戏日按人设产出「今日倾向」：爱好标签映射动词加权（爱钓鱼的多去钓鱼、爱流浪的少蹲田），七维分值修边（勤低偶尔摸鱼、俭高抠门经营、勇高冲竞争）。
2. 双层：服务端权重表管频率（提示词层管语气，由习惯语承载）。
3. 习惯语示例：「热心得发亮，今天多去水边坐坐。」
4. 确定性：种子 = f(游戏日, 卡id)，现实时钟不参与——回放一致性硬约束。

## 3. 在线交互机制（2026-11-20 补充裁决）

1. **托管纯手动**：按「启动托管」才开工，任何下线/登录/进村路径均不自动启用司机。
2. **人在线不碰键**：司机照常自主生活（种地赶集聊天），与人不在时行为一致；玩家回来从当前位置无缝续上。
3. **单按任意键 = 零反应**：纯防误触垫片——不打断、不让位、不通知司机。
4. **连击取消**：任意两击间隔 ≤1 秒即取消本次托管（链式判定，连按三下也取消，中断超 1 秒则断链仅让位无效）。取消瞬间司机松键自然停，走多少算多少，落点报回服务端对账，偏差超限走现有 drift 重规划。
5. **取消后司机待命留场**：进程不灭、记忆不丢，玩家重新按「启动托管」即续。
6. **指挥消息照旧**：不打断，干完手头这摊再回应。

## 4. 执行层原理（2026-11-20 裁决）

**虚拟按键方案**：司机的每段移动在客户端转成一次虚拟按键，走原版完整管线（按键 → 碰撞检测 → 走路动画 → 相机跟随），与玩家亲手移动表现完全一致。服务端五道限制闸不变（A* 可走格规划 / 安全边距 / 航点确认环 / 交互环吸附 / 私有闸门），新增「原版本地碰撞与服务端规划对不上 → 从真实位置重规划」失败模式（与现有 drift 逻辑同构）。

## 5. 验收标准

1. 钓者人设跨多日的动作分布显著偏向钓鱼（相对拆掉爱好后的同一张卡）。
2. 守财奴人设的赶集交易均值显著高于其清零七维后的对照。
3. 同输入两次调用结果逐字相同（回放一致）。
4. 无卡角色行为与旧版一致（中性基线）。
5. 新 globals 键登记后存档键审计门绿。

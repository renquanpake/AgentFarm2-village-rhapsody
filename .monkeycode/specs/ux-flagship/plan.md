# 旗舰体验优化规划（体验线总纲）

Feature Name: ux-flagship
Updated: 2026-09-30
定位：进化书战略第二条线（智能线 > **体验线** > 内容量 > 画面量级）的总纲。与既有三份规划咬合：roads-landmarks.md = 城市骨架（路/地标/指引），trade-hall = 交易 UX，NPC 对话 = 社交 UX；**本规划补齐感官、流程与双用户（玩家 + Agent）的体验层**。

## 0. 旗舰级的定义（本规划的北极星）

1. **三秒可感知**：每个玩家操作在三秒内有声/光/字反馈，零静默操作。
2. **零文档上手**：新玩家 10 分钟、新 Agent 30 分钟，不读任何外部文档完成核心环（走→看→交易→社交）。
3. **世界可预期**：昼夜/天气/节日/NPC 作息全部可观察、可预告、可回忆。
4. **信息有层级**：一眼（HUD）→ 一屏（面板）→ 一图（大地图）三层信息架构，各层不越权。

体验项总量 19 项，其中 **9 项零依赖可穿插**、**6 项等市政数据**、**2 项等经济解冻**、2 项半天核实（U11/U12 原版接管点）。

## 4. 验收门（双金路径 + 预算）

| 门 | 标准 |
|---|---|
| 玩家金路径 | 新号 10 分钟：引导环 → 凭小地图找到交易区 → 挂一单 → 收到成交 toast+coin 音效 → 看见 NPC 名牌活动；全程 0 文档依赖，每步反馈 <3s |
| Agent 金路径 | 冷启动 Agent 30 分钟：凭世界说明书 + observe 一句话完成 1 次交易 + 1 次社交 + 1 次跨场景导航；0 次"问路"失败 |
| 性能预算 | mod DOM 节点数以当前基线为上限基准（实施首日实测登记）；帧率无回归（八道门内含） |
| 回归 | 常规八道门 + 5128 哈希零变更 + vitest 全绿 |

## 5. 不做（边界）

- 不做皮肤/时装商店、成就系统、排行榜大屏、多语言、移动端适配、过场动画、剧情系统。
- U6 快传的经济定价、U2 任务奖励金额，均等 M-B1 影子窗判门后再定参数（结构先行，参数后填）。

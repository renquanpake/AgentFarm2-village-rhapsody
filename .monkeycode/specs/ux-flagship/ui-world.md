## 1. UI 旗舰化（V 系列）

### V1 设计系统定稿（一页 token sheet）
- 色令牌语义分层：`surface（bg/panel/panel-deep/glass-*）/ text（text/text-dim）/ state（success/danger/waiting）/ accent（gold/amber）/ 环境（wood/moss/sky/sky-*）/ 纸感（paper/paper-hud）`——26 个现有令牌归位，只删增不改名（149 处引用零迁移）。
- 补 3 类缺失令牌：字号阶 `--af-fs: 12/13/15/18/24`；间距阶 `--af-sp: 4/8/12/16/24`；动效 `--af-dur: 80/150/250ms + --af-ease: ease-out`。
- 单源化：令牌声明收敛到 mod 内嵌 style 单一声明块，硬编码色值清零（见验收 css-audit）。

### V2 组件库 12 件规范
`toast(有,M2) / panel / button / chip(有,HUD) / badge / list / card / tab / empty-state / loading / pin / tooltip`——每件四行规范：用途、尺寸、状态、所用令牌。存量 toast/chip 按规范回补，其余 10 件随需求实例化（规范先行，避免每个面板重新发明）。

### V3 图标体系（SVG 24px 网格）
一套三组：地标 8 类（monument/building/bridge/fountain/tower/dock/gate/stall，市政 L2 用）、功能 12 个（订单/背包/日程/天气/设置/帮助/私聊/邮局/银行/行情/驿站/图鉴）、天气 4 个（晴/雨/风暴/雾）。统一单色 `currentColor` 可染，DOM 面板与小地图共用一套源。

### V4 动效三档
反馈 80ms（按下/高亮/勾选）、入场 150ms（toast/面板滑入+淡入）、过渡 250ms（面板切换/图层显隐/昼夜 tint 渐变）；统一 ease-out。金币滚动等存量动画保留。

### V5 渲染分工原则（跟世界走=Cocos，跟屏幕走=DOM）
| 层 | 管什么 | 例 |
|---|---|---|
| DOM | 跟屏幕的面板/HUD/设置 | toast、图鉴、设置、HUD 四分区 |
| Cocos 反射 | 跟世界坐标的东西 | NPC 名牌、行动气泡、目的地 pin、粒子、告示板内容、tint 层 |
判定规则一句话：镜头动了它该跟着动 → Cocos；镜头动了它钉在屏幕上 → DOM。杜绝同类元素两处实现。

### V6 小地图视觉规范
4 色 + 玩家箭头 + 目的地 pin；配色做色盲安全（水/障碍/路/地标四基色对 deuteranopia/protanopia 可辨，对比度 ≥3:1）；图层显隐开关（市政 L2 的视觉规范落点）。

## 2. 世界视觉旗舰化（W 系列）

### W1 场景视觉身份（一场景一母题）
12 室外卫星场景母题表：河边=水汽波光、稻田=金浪风纹、温泉=暖雾、龙哥家=喜庆红、飞机场=金属反光、山顶=云海、密林=斑驳光斑、吊桥=绳木、索道=钢缆、牧园=栅栏青草、春水岸=柳绿、后山=岩石灰。落地三件套：氛围 tint（W2 复用）+ 主题 decor 摆放指南 + 地标视觉锚（市政 landmarks）。室内 13 场景 = 家具包风格差异（decor 现有 60 件按宅主性格分配指南）。

### W2 昼夜与天气视觉（音画同步）
- 昼夜 tint：Cocos 全屏单层（正午 0% → 黄昏橙 15% → 夜深蓝 20-25%），随历法小时渐变（250ms 档），与 U11 昼夜 BGM 切换同一触发源（音画同步）。
- 天气视觉：雨天=灰蓝 tint+雨丝粒子（下落线精灵，同屏 ≤60）；风暴=乌云 vignette 边框+闪电白帧（150ms，随 calendar 雷击事件同步）；雾=低透明白层。
- 全部 mod 层叠加，零原版资产改动。

### W3 建筑视觉融合规范（生图件落地四规则）
1. 接地阴影：建筑底部内置椭圆阴影（prompt 内置，禁止后期贴片）；
2. 门位对齐：画面门/门帘落在 walkable 门格（A 挂牌=原版门不动；B 覆盖=门格坐标写入 manifest）；
3. 路面衔接：建筑底边与最近路格之间 ≤1 格留白（衔接由市政路数据保证）；
4. 同色板：建筑用 W4 世界色板，禁止出挑高饱和色。
A 挂牌 vs B 覆盖决策树补一条：原版建筑轮廓完整 → 一律 A 挂牌（保 5128 观感连续）；只有新环空地才 B 覆盖。

### W4 生图管线 v3（palette v1 → v3）
- 世界色板 16 色 = 村系暖色 6（对接 UI 的 gold/amber/wood/moss）+ 环境 6（草/水/石/路/叶/天）+ 黑白灰 2 + 高光 2；一次定稿进 manifest，UI 令牌与生图色板同源对照表入 docs。
- prompt 模板升级：style-v2 三条（纯白底/单体/16 色）保留 + 新增三条（接地阴影内置、3/4 俯视透视锁定、主光源左上）。
- 断言自动化：量化后唯一色数 ≤16、非纯白底占比检查进管线，超标即拒收重生成；CC0 兜底流程保留。

### W5 呼吸感动画清单（世界活着）
| 动效 | 载体 | 成本 |
|---|---|---|
| 水面波光 | shuich 层上叠加 2 帧波纹精灵（沿水域随机布点 ≤20） | 低 |
| 炊烟 | 有灶房屋顶 3 粒子/秒上升渐隐（11/17 时饭点增强） | 低 |
| 旗帜 | 村广场纪念碑旗 2 帧摆动 | 低 |
| 夜间萤火 | 21 时后河边/密林 5-8 个光点粒子缓浮 | 低 |
全部 Cocos 粒子/帧动画，同屏粒子总上限 120（含雨丝），超限自动降级为静帧。

### W6 daditu 大地图旗舰化
路网/地标/区域色块全图渲染（直接喂市政 P1a 的 roads/landmarks 数据）+ 场景点击跳转 + 与 U5 图鉴面板共用一套数据源；小地图与 daditu 共用 V6 配色规范。

## 3. 约束红线

- **5128 原版哈希零变更**：一切视觉 = mod 层叠加 + 新增生成资产；TMX 原版 5 层只读（新环走新增数据文件）。
- 性能预算：同屏粒子 ≤120；tint 全屏单层 GPU 合成；DOM 节点预算沿用 plan.md（实施首日实测登记）；帧差门见验收。
- 经典观感保护：A 挂牌优先于 B 覆盖；tint 强度上限写死（夜 ≤25%），防止"原版变味"。

## 5. 验收门

| 门 | 标准 |
|---|---|
| token 审计 | `tools/css-audit.mjs`：mod 内硬编码色值 = 0（新增代码），全部走令牌；字号/间距走令牌 |
| 16 色断言 | 所有新增 PNG 量化后唯一色数 ≤16，管线自动拒收 |
| 色盲安全 | 小地图四基色在 deuteranopia/protanopia 模拟下两两可辨（截图人审） |
| 视觉金路径 | 同机位三张截图（正午/夜晚/风暴）一屏可辨；建筑截图按 W3 四规则逐条人审（接地/门位/衔接/色板） |
| 帧率 | 粒子与 tint 开/关帧差 <5%（八道门内含实测） |
| 回归 | 八道门 + 5128 哈希零变更 + vitest 全绿 |

## 6. 不做（边界）

- 不做角色/NPC 重绘、原版 tile 重制、3D/镜头缩放、过场 CG、多主题皮肤切换、光照贴图烘焙。
- 呼吸感动画只做清单内 4 件，加做需走价值判据（可观察性/氛围增益二选一），防动效通胀。

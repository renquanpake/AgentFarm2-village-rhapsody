## 1. 现状盘点（代码事实）

### 1.1 地图机制（决定"还能扩多大"的硬约束）

- **原版村景 TMX = 133×117 格**（`tm.getMapSize()`，village-farm.json waterW/waterH 同值），原版 77×61 村庄居中，偏移 (28,28)。
- 现有"扩展"（77×61→133×117）**完全是免费的**：原版 TMX 美术本身就画到了 133×117（外围田野/树/水都是原版图层 caodi/shilu/shuich/mulan/mulan2），mod 做的只是：
  1. 入口 collider +2800 平移对齐（`shiftPassages`，agentfarm.js:717）；
  2. 出生点短窗拉回（`fixSpawnAfterReturn`）；
  3. 扩展区阻挡盒注入（宅基地/水面/栅栏三层，`injectBlockers`:917）+ 每帧回滚兜底；
  4. 小地图扩展版底图（`/af/mapgrid` + afMapBg，原版区透明透羊皮纸）。
- **玩家移动边界**：原版 `PlayerMoudle` 把玩家 clamp 在村区，mod 通过阻挡盒物理挡回 + 回滚实现"能走进扩展区"。扩展区之外没有美术——**133×117 是原版美术的物理上限**。
- 相机：A8 导演镜头已做观战跟随（`__AF_CAM__`），玩家相机 clamp 是原版行为，扩展时可能需要反射 override 相机 limit（当前 +28 环没遇到，说明原版相机本身允许走到 TMX 边界）。

## 2. 发散：功能性建筑菜单（v2：按"有啥用"重排，砍 7 保 5 + NPC 对话）

**价值判据**（进化书智能线优先）：一栋建筑/一项功能只有在改变 ①Agent 决策空间 ②经济拓扑 ③可观察性（玩家/日报看见什么）三者之一时值得做。纯"给已有动作摆个牌子"（场所化）一律砍。

### 2.0 前置研究结论（v2 新增，改变排产的关键事实）

**A. NPC 对话是全系统最薄的一环，且补强几乎零成本**：
- 现状：`act talk`（ws.ts:962）只有两种固定回复——无摊位 NPC："我只是个村民，不卖东西"；有摊位 NPC：价目表+"报物品 id 和数量就能买"。`npcs.json` 的 `talks: [105,...]` 是对话行编号，**文本在客户端加密资源里，服务端根本没有对话内容**——NPC 没有人格、无上下文、无 LLM。
- 对比：托管 Agent 已有全套 LLM 对话（dm_in/dm_send/chat + C5 八卦传播 + M7 双档路由 + 10 分钟结果缓存 + 无 Key 降级）。
- 做法（additive，不碰现有分支语义）：`act talk` 回复改为三段式——①价目表（原逻辑保留）②NPC 人格对话（`llm.chat(taskType='dialogue')`，system prompt = npcs.json 扩展 persona 字段（名字/身份/口头禅，数据文件 additive）+ 当前时段活动（schedule.ts 纯函数可查）+ 天气/节日（calendarDay）+ 该 NPC 相关 gossip（C5 记忆检索）；玩家未配 Key 且全局 provider 缺时回落固定回复）③缓存：同 NPC 同场景上下文 10 分钟 TTL（router.ts ResultCache 直接复用，玩家 Key 计量现成）。
- 成本：约 1 天（模式全部现成）+ npcs.json 26 名 persona 文案（可委托 agnes 批量生成，单文件工具活）。
- 收益：整村"活起来"的最小改动；A9 画报日报/observe 认知直接多一层社会素材；配合建筑后 NPC 台词可带位置（"银行今天开门"）。

**B. 装修（decor）系统：机制全齐，画面为零**：
- 现状：B10 完整链路已跑通——60 件家具目录（decor.json，六类×10：花/水/结构/灯/路/植，price+points）、宅基地点位表（`decorSpotsFor` 房屋外扩 2 格可走格）、放置扣币/移除退 50%、庭院积分+完成度评比（`/af/decor-board` 排行端点）、满分触发 `decor.contest` 事件送 C8 视觉模型评分、节日春花会/冬雪雕就是装饰赛。
- **缺口 1（画面）**：decor.json 全部 `artRef: null`——60 件家具**目前没有任何视觉**，玩家布置了只在数值上存在。art-gen 管线（C8 v2 纯白底铁律 + art-qa 机审 60/60）+ Cocos 反射摆放（M4 已验证挂节点）补上即成。
- **缺口 2（室内）**：`decorSpotsFor` 只从 `spawn-points.json` 宅基地 rect 派生（仅村景 7 处）；102-113 室内场景（ready-empty-collide=整间可走）不支持布置。扩展 = decorRec 加 `scene` 维度 + 点位表按"场景 rect"派生（室内空碰撞=全房可摆，简单）。数据 additive（`decorData` 加字段，旧档兼容：无 scene 默认 2）。
- **缺口 3（公共建筑家具包）**：银行/邮局这类公共建筑的"装修"= 新增 catalog 类别 `building`（保险柜/信箱/告示板/柜台 20-30 件），owner='village' 固定点位（buildFacility 已有 owner 机制，cooking.ts:47 玩家自建 barn/mill/kitchen/kiln 同一条路），村里摆满公共家具 = 全村装饰板（village 级 points，复用 courtyardRanking 逻辑加一个"全村"榜）。

**C. NPC 日程挂建筑（活的世界第二层）**：
- schedule.ts `npcDecision` 是纯函数（天气/节日覆盖 > 时段活动 > 归家），POI 表（`NpcPois`）只有村中心/河边/矿点/家门四类。建筑落地后 POI 表 additive 加"银行/邮局/宴会厅"点位：银行 NPC（新增 1-2 名 banker）白天在岗、邮局 NPC 上午派件、节日全员 10-20 点聚宴会厅（替代现村中心聚集）。改动=数据+纯函数分支，零引擎触碰；`/af/npc-schedule` 端点自动反映。

## 4. 关键技术点与验证清单

### 4.1 越界渲染方案（+28 环的核心风险点）

原版 TiledMap 组件在 133×117 之外无美术。三条路线（按推荐序）：

1. **克隆图层贴片（首选）**：mod 反射读 TMX 各图层（caodi/shilu/shuich/mulan/mulan2）末 28 格 TileMapData，在 TiledMap 节点外生成 4 个 sibling `cc.Sprite`（东/西/南/北环），用 `cc.SpriteFrame`（原图图集区域）逐格重画，做接缝去重（环形角落 4 个重叠格只画一次）。优点：与原地图同图集同风格，零新素材；缺点：远景重复纹理（28 格内可接受，77 格明显）。
2. **art-gen 新地块**：新环用地形贴图（草地田埂/小河/树林 4-6 种变体，纯白底铁律 + art-qa），Sprite 网格铺设。视觉更新鲜但风格一致性靠生图管线把控（已有 52 件生图先例）。
3. **混合**：内侧 12 格克隆（与原版自然衔接），外侧 16 格 art-gen（新区域新地貌：比如整条河往南绕出新湖泊 = 新钓鱼点/温泉扩展）。**推荐**：克隆保证衔接、art-gen 提供"新地方"感。

验证：dev-server 开场景 2 → 四方向走到新环 → 截图对比接缝；nav-replay 全量回归（新 189×173 网格）；ui-smoke 不因新 DOM 破 17 项。

### 4.2 玩家边界/相机

- 现 +28 环已走通（阻挡盒+回滚），说明原版移动 clamp 允许到 TMX 边。
- 新环需要在 mod 层反射扩展移动上限：读原版 `PlayerMoudle` 的边界常量/相机 limit 节点，按新尺寸放大（先探明具体机制——这是**开工前必做的 1 天 spike**，写 `tools/probe-camera-clamp.mjs` 打印相关节点/常量）。
- 失败兜底：即使相机 clamp 扩不开，玩家仍可用 move_to（服务端权威）抵达新环建筑，人类玩家手动移动受限——体验降级但功能不断。

### 4.3 数据与工具链（全现成）

- `gen-nav.mjs`（--render/--check）、`build-scene-collisions.mjs`、`nav-replay.mjs`（210 例）、八道 CI 门：新网格重跑一遍即可。
- buildings.json（新，单一事实源）：`[{id, scene, name, kind, rect, door, poi, interior?, hooks:[...]}]`，全 A/B 层建筑收敛于此（trade-hall.json 并入此 schema，单文件不另起炉灶）。
- observe regions：建筑区域名 + 功能 hint（"银行：存取与计息，move_to near=bank"）——D2 区域级原则直接套用。

### 4.4 经济闭环挂钩（进化书战略：智能线优先）

每个建筑都挂经济回收/投放触点，喂 inflationIndex/feeMultiplier 数据：银行利息（投放）、诊所/旅馆/保险（回收）、集市摊位费（回收，已实现）、工坊材料溢价（回收）。影子市场 D8 修好的跟随能力 = 未来"商会广场真实结算"（C 层）的验收依据，M-B1 14 日判门是前置门。

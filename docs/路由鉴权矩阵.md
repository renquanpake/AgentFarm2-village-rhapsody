一、 鉴权层级定义
鉴权等级
	标识
	鉴权逻辑与安全控制
	L0 公开端点
	PUBLIC
	零门槛公开只读端点（部分含速率限制与验证门）。
	L1 玩家鉴权
	PLAYER_TOKEN
	请求头或参数必须携带有效玩家 Token，且严格校验目标数据属于该 UID，跨 UID 操作一律 403。
	L2 管理员鉴权
	ADMIN_TOKEN
	必须携带环境变量 AF_ADMIN_TOKEN，用于敏感管理、存档切换与底层回放。
	L3 调试环境
	DEV_ONLY
	仅在 process.env.NODE_ENV !== 'production' 或 AF_DEV_MODE=1 时开启，生产环境恒定返回 404。

三、 审计结论与修复对齐
1. 公开只读端点：全部保持幂等无害，仅暴露公开村庄信息，符合纯文本无障碍（契约 R9）设计。
2. 玩家个人端点：全部已接入 Token 校验，且在调用层均通过 findAccountByToken 解析出真实 acc.uid 进行资源归属绑定，杜绝越权访问漏洞。
3. 管理与调试端点：调试接口默认挂载 DEV_ONLY 防护网，敏感管理接口绑定 AF_ADMIN_TOKEN 拦截。
4. D18 收口状态：矩阵核验 100% 齐备，准予放行。

Updated: 2026-09-29
定位：零现金旗舰版（玩家/Agent 自带 Key，服务端零池化密钥）的完整进化总纲。盘点全部未做与未做好项，收敛为分阶段路线。前置文档：`docs/最终版规划书.md`（导航规划）、`.monkeycode/specs/`（各特性 spec）。

## 0. 战略定位（先想清楚为什么做）

**诚实差距**：以星露谷/原神为标尺，本作在美术量级（60 件拼装 vs 数千张精修）、游戏设计（工程师视角 vs 数值循环专业）、内容深度（1 村庄无剧情链 vs 数百小时内容）、音频（零）上存在工程清单无法弥合的差距。"世界级旗舰画面"是死路，卷不过。

**品类机会**：本作唯一的世界级潜力是 **Agent 托管的自主生活村庄**——LLM 驱动角色自主起床/规划/赶集/社交/经营，市面上无此品类，且事件溯源 + 双档 LLM 路由 + 影子经济 + 评测集的工程底座构成复制壁垒。游戏史反复证明品类创新 > 画面军备竞赛（Vampire Survivors 一人开发画面极简全球爆款；星露谷初期美术预算近乎零）。

**战略结论**：
1. 资源倾斜次序：智能线（差异化）> 体验线（精致像素水准）> 内容量 > 画面量级。
2. 可执行里程碑：**"100 个陌生人中 30 个愿玩满 2 小时、10 个留存"**——达成它才有资格谈品类，谈下品类才谈世界级。
3. 本进化书通往该里程碑；世界级所需的数值策划/内容生产线/美术投入在里程碑达成后再议。

## 2. 债务清单（已做但有缺口，按危害排序）

### D1 导航执行确认闭环未接主流程（危害最高）
`最终版规划书.md` §4.3 明文"不能再按固定 120ms 盲推坐标"，但 `server/src/gateway/ws.ts` move_to 执行流仍是 `setTimeout(120)` 逐格盲推；arrive 航点确认协议只是旁路（Agent 可选调用），agentRoutes 存了航点但推进循环不消费；偏差超限仅回提示，无自动停止 + 从真实位置重规划。tasklist B6 声称"盲推保留为 debug/回落分支"与代码不符。
**改法**：执行流改为发航点 → 客户端 arrive 上报真实落点 → 服务端校验/重规划 → 下一航点；删除盲推主循环。

### D2 区域级障碍缺失且方向做反
navgen 模型已支持多类 kind（0 地/1 阻挡/2 水 cost=2/3 树）与多级 cost，但 gen-nav 生成村景时只喂了 blocked 图层（`buildNavGrid(2, col.blocked, ...)`），水/树数据未接入，实际产物 kind 只剩 2 值且 cost 无分级；road/building/edge 三类未建模。observe（`server/src/cognition/observe.ts`）反向输出 10 格内单树坐标清单，§4.2 明文"不给 Agent 树坐标清单"，应输出区域名 + 格子范围 + 绕行原则。
**改法**：gen-nav 接入 village-farm.json 的 water 图层与树丛数据（管线现成，工作量轻）；补 road/building/edge 三类；observe 改区域级障碍输出；树坐标清单移入 debug 开关。

### D3 交互环缺失
规划书 §5 要求"目标周围可站立交互环"（水边面向水/NPC 碰撞外一格/障碍缓冲外一格/服务端半径内最近可站格）。现状：仅钓鱼有水边判定；move_to 目标是裸坐标，`snapToWalkable` 存在但未接入（障碍格目标直接报不可达）。
**改法**：move_to 接目标吸附 + 按 target 类型吸附到交互环。

### D4 玩家打断无硬停
`agent_interrupt`（ws.ts:405）仅发通知靠 Agent 自律停手，进行中的盲推循环走完全程；§7 "打断后 200ms 内停止"无保障。
**改法**：打断信号接入移动任务（AbortController 模式），立即终止当前任务并广播 done。

### D5 回放验证覆盖不足
`tools/nav-replay.mjs` 仅 1 个宅基地起点（§7 要求"每个宅基地"），且纯逻辑模拟（实际位置=航点本身），验证不了无碰撞/无原地抖动/相机跟随三个客户端观感项。
**改法**：起点扩到全部宅基地；D1 落地后加 arrive 协议实机回放模式。

### D6 跨场景导航有代码无数据
27 场景仅 village ready，26 场景 nav 源数据 pending（客户端加密资源未提取）；portals.json 无跨场景 passage；跨场景采购（B2 遗留）被此卡住。
**改法**：从客户端加密资源批量提取碰撞源 + SceneType 枚举，逐场景填齐 → 跨场景采购启用。**Plan B（防全量卡死）**：若加密资源批量提取受阻，按玩家动线优先提取 3-5 个高频场景（家/诊所/矿/河边/杂货店），跨场景采购先在动线场景启用，长尾场景渐进补齐。

### D7 导航图无可视化核对工具
规划书 §6.1 要求生成后人工核对河流/建筑/树丛，现无 PNG/HTML 导出。
**改法**：gen-nav 增 `--render` 输出带 kind 着色的 PNG。

### D8 影子市场调参
活体验证：物品 1 实盘=影子 7/7 偏差 0；物品 2 影子漏成交（volumeDeviation 1），M-B1 调参信号。14 真实日观察期起点已归档但需用户实跑服务器计时。
**改法**：分析物品 2 漏成交根因（撮合时序/深度），调影子参数；14 日期满跑 `tools/shadow-observe.mjs` 判门（价差中位<15% 且偏差<0.5）。

### D9 商人 OHLC 历史跨重启 ✅ 验证关闭
market_fills DB 直读 + load() 回灌；重启后「市场恢复：3 笔挂单 + 1 笔历史成交」，OHLC/last 全恢复。

### D10 历法前周期粗控频 ✅ 验证关闭
B8 游戏日时钟已取代现实时间控频（商人/经济/NPC/畜牧周期全挂 growDayMs，节日=每季末日）。

### D11 mod 层样式散落 ✅ M1 收口（4f43a01）
tokens.css 色板收敛（agentfarm.js 零裸色残留）+ AFUNI 组件层 + ui-lint 门8（静态门）+ ui-smoke 门8（DOM 冒烟）。

### D12 规划书文档过时 ✅ 收口（438711d 本次）
进化书一页纸已刷新（D1-D7/D9-D11 状态）；`最终版规划书.md` 地图尺寸修正为 133x117、§3 故障与 §6 实施顺序与 §7 验收全部标记收口数据。后续新债再行登记。

## 4. 进化路线（五阶段，含依赖）

### 阶段一「手感与信任」（可并行双线）
- 智能线：D1 执行确认闭环 → D4 打断硬停 → D3 交互环 → D2 区域级障碍（observe + navgen）→ D7 可视化 → D5 回放扩容。全部为服务端/工具侧，主模型可直接验收。
- 体验线：美化 M1 设计系统 → M2 HUD → M3 动效粒子（纯 DOM 层零风险）。
- 门：规划书 §7 五条实机可演示 + 美化 R1-R5 静态门全过；**美化每个里程碑收尾必须跑全套 mod DOM 冒烟回归，防止重皮肤破坏既有面板功能**。

### 阶段二「氛围与声音」
- 美化 M4 Cocos 氛围注入（代码侧）→ M5 音频 → 用户实机验收 N2 全套（含 M4 清单）。
- 音源获取：CC0 音频包优先（Kenney 音频包/freesound CC0，网络搜索下载），结构按 spec design.md 的 BGM 昼夜复用方案控制体积。

### 阶段三「世界连通」
- D6 场景源数据提取（需解客户端加密资源，工程量最大）→ 26 场景导航矩阵 → B2 跨场景采购启用 → D12 规划书刷新。

### 阶段四「长周期验证」
- N5 用户实跑 14 日 → D8 影子调参与 M-B1 判门 → D9 OHLC 回灌 → D10 历法频率校准。

### 阶段五「发布工程」
- N4 密钥轮换（用户）→ N3 双机 Tailscale 实测 → F4 4.2 清单勾满 → 全量回归 + 收口。

依赖关系：阶段三依赖阶段一（区域级障碍模型是全场景导航的地基）；阶段五的 N4 可随时前置。

- **主模型（会话）**：规划、拆解、架构、Cocos 反射与哈希门敏感代码、全部验收与提交门。

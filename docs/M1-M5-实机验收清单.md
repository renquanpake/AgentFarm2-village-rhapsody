# 旗舰 UI M1-M5 实机验收清单（M4 氛围/运镜为重点）

> 前置：服务端重启一次（拿 `/af/calendar` 的 `hour` 字段）+ 浏览器强刷（Cmd/Ctrl+Shift+R）。
> 每项标注 通过/不通过 + 一句话现象即可回传。

## 一、30 秒主链路

1. **登录页皮肤**：登录页整体暗蓝玻璃+金边，按钮悬停有 brightness 提升、按下下沉 2px。
2. **进入 toast**：点「进入」后顶部弹「已进入游戏 · <昵称>」+「已连接 · <昵称>」两条 toast（羊皮纸风格，2.5s 自动消失）。
3. **HUD 四分区**（登录后）：
   - 左上：金币数（有数字滚动动画）
   - 右上：历法胶囊「📅 第N日 · 季 · 天气」
   - 右下：托管状态胶囊（未连 Agent 显示「🤖 Agent 未连接」）
4. **SFX**：进入/连接时听到短促提示音（需首次点一下页面解锁音频；BGM 随之起，昼曲/夜曲按时段切换，19:00/05:00 边界）。

## 二、M4 氛围观感（核心，需 2-3 分钟）

5. **昼夜 tint**：切到 18-20 点时段（或生产钟等时段推进），画面整体加一层暮橙色调（约 26% 透明度的橙叠加）；夜间变蓝。
   - 快速验证：控制台 `fetch('/af/calendar').then(r=>r.json()).then(d=>console.log(d.hour, d.days[0]))` 看当前小时；再改存档或等推进。
6. **季节粒子**（随 /af/calendar 的 season）：春=粉色花瓣、夏=萤火虫点光、秋=落叶、冬=雪。粒子层在画面上、面板下，pointer-events 不影响操作。
7. **天气粒子优先**：当天是雨/雪/风暴时，粒子按天气（雨雪条状/点状）而非季节。
8. **灯笼光晕**（夜间）：村中灯笼出现柔和光晕圈（夜间才挂，白天无）。
9. **呼吸脉动**：待机时主角有极轻微缩放脉动（约 1.2%，不移动位置）。
10. **性能**：满屏粒子 + 面板开合同时观察 DevTools，帧率应稳在 45+（fps<45 持续 3s 会自动降粒子池 50%）。

## 三、M2/M5 交互

11. **托管操作 toast**：点「启动托管」/「停止托管」/「⏸ 打断」/「▶ 恢复」各出一条 toast（成功绿边/失败红边 + 对应音效 ok/err）。
12. **kicked 提示**（可选）：双端同账号登录，被踢端顶部弹 5s 红色 toast（原来这里是 alert 弹窗，已替换）。

## 四、主角行走表现（批2 P1 遗留，`v2.1-p1-visual-settled` 归档）

服务端权威位置全部正确（无头断言：dir 步随 / 黑洞重放 / move_to 终点对齐均 0px 偏差），但画面位移由 tween 直接摆位，原版走路帧动画未接管。真机需确认：

13. **走路动画**：正常玩家流程（非测试注入）下用方向键/摇杆移动主角，角色应播放原版走路帧动画（脚步摆动），不是平滑滑动或瞬移。
    - 已知根因：快速进村路径下玩家被新手教程置进 `stateClass` 缺项状态，`changeDir` 抛 `Cannot read properties of undefined (reading 'checkEnableState')`，客户端已在 try 内调用后退化为纯位置收敛。
    - 若 13 项不通过但位置正确，属表现层缺项，不影响存档与服务器数据。
    - **禁止为修此项改原版状态机核心代码**（架构师 2026-10-06 裁决：防止引入新的未知回归），维持现有 tween 兜底位移逻辑。
14. **托管行走**：连接 Agent 后观察自动寻路，角色沿路径移动时同样应有走路帧动画；跨场景传送前后角色不应出现悬空或错位。

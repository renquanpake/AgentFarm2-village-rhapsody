## 一、私有仓库凭据

仓库是私有的，匿名 `git clone` 会得到 `Repository not found`。

凭据优先级：

1. **工作区里已有本地凭据文件**（已 gitignore，不入库）：`.monkeycode/local/credentials.md`。文件存在就直接读它。
2. 文件不存在 → 向用户索取 GitHub PAT（需要 `repo` 权限），然后写入 `/root/.netrc`：

```bash
python3 - <<'PY'
import os, stat
TOK = "<把 PAT 粘这里>"
p = "/root/.netrc"
lines = [l for l in open(p).read().splitlines() if not l.startswith("machine github.com")] if os.path.exists(p) else []
lines.append("machine github.com login x-access-token password %s" % TOK)
open(p, "w").write("\n".join(lines) + "\n")
os.chmod(p, stat.S_IRUSR | stat.S_IWUSR)
print("netrc 已写入")
PY
```

> PAT 不要提交进任何仓库文件。`tools/security-check.mjs` 会扫 `git ls-files` 里的 GitHub PAT 模式，gitignore 的本地文件不在扫描范围内。

## 二、克隆

普通克隆即可（仓库约 612MB，含大量原版贴图）：

```bash
git clone --branch 260103-feat-playable-ship https://github.com/renquanpake/AgentFarm2-village-rhapsody.git agent-farm
cd agent-farm
cd server && npm ci --no-audit --no-fund && cd ..
```

**受限环境（磁盘小 / 克隆超时）**用稀疏检出，只取代码与门禁数据，省掉 343MB 贴图与 172MB `server/public/sprites`：

```bash
git clone --filter=blob:none --no-checkout --depth 1 --single-branch --no-tags \
  --branch 260103-feat-playable-ship <repo-url> agent-farm
cd agent-farm
git sparse-checkout set --no-cone \
  '/.monkeycode/' '/docs/' '/tools/' '/deploy/' '/.github/' '/LICENSES/' '/data/' \
  '/client/mod/' '/client/src/' '/client/index.html' '/client/main.*.js' '/client/style-*.*.css' \
  '/client/assets/md5_util.js' '/client/assets/web_downloader.js' '/client/assets/audio-cc0/' \
  '/client/assets/resources/' '/client/assets/internal/' '/client/assets/main/' \
  '/client/cocos2d-js-min.*.js' '/client/physics-min.*.js' '/client/splash.*.png' \
  '/client/original-hash.json' '/client/favicon.*.ico' \
  '/server/src/' '/server/src-experiment/' '/server/test/' '/server/save/' '/server/examples/' \
  '/server/afserver.mjs' '/server/package.json' '/server/package-lock.json' \

```

跑 `node tools/dev-env-check.mjs` 确认路径齐全——脚本会逐条告诉你缺什么、怎么补（`git sparse-checkout add <路径>`）。

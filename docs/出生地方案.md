# AgentFarm2 新玩家出生地方案

> 需求：每个新玩家有自己的出生地（不挤在原版主角家门口）；地图可以扩大，风格必须和原版一致（照搬性质），但不能有"复制感"；NPC 不动（能交易正常交易，agent 可买），无关 NPC 后续删除。

## 一、技术事实（已验证）

1. **地图 = import json 里内嵌的 tmx XML**（`cc.TiledMapAsset.tmxXmlStr`，明文！）
   - 家门口地图资源：`assets/resources/import/c1/c18fa04a-….json`（29×29 格 ×100px = 2900×2900）
   - 纹理/场景 prefab 都**不用动**，只改这一个 json 里的 XML（扩宽高+每层 data 追加 tile）
2. **可种地区域**是另一个明文 json（`zhujuejiaMapPlant`，29×29 的 1/0 数组）——同步扩
3. **碰撞 = 场景 prefab 里的物理 Collider**（Box/Polygon，树/墙都有），不是 tile 属性
   → 扩区障碍物碰撞由 mod.js **运行时注入**（场景加载后按布局表挂 BoxCollider），不动 prefab
4. **出生点** = 服务器给新玩家的 `playerData.playerPos`（场景坐标）——服务端一个表就搞定

## 二、布局设计（防"复制感"）

家门口地图从 **29×29 扩为 29×61**（向下扩展 32 行 ≈ 3 公里纵深），容纳 **8 户**（2-8 人小服上限）。

```
┌────────────── 原版院子（第 1 户·主角） ──────────────┐
│  原版房子+院墙+田地（完全不动）                         │
├────────────── 树篱分隔带（原版树 tile）──────────────┤
│  第 2 户：房子偏左 + 院门朝下 + 田 3×4                 │
│  树篱 + 小路（原版石板 tile）                          │
│  第 3 户：房子偏右 + 院门朝右 + 田 2×5                 │
│  树篱 + 小路                                       │
│  第 4~8 户：……每户参数化随机（房子偏移 0-2 格、        │
│  门朝向 3 选 1、装饰树/花/石头的 gid 组合不同）          │
└──────────────────────────────────────────────────────┘
```

**防重复三原则**：
1. 每户布局参数化变化（房子位置、门朝向、院子形状、装饰组合）——不是整块复制
2. 户间用"树篱+小路"过渡（照搬原版树/石板 tile），间距不一
3. 新地块的地面/植被用原版 tileset 但排列随机化（树不整齐、草不规律）

**所有 tile 都来自原版 tileset**（fzs/sku/di1/cdi/byuand/qskuais/shuic/haishui/skuai/skuai2/szi/trangs），风格 100% 一致。

## 三、实施步骤

1. **工具脚本** `tools/expand-home-map.mjs`：
   - 解析 tmxXmlStr XML → 改 width/height → 每层 data（base64+zlib）解码 → 追加新行 → 重编码写回
   - 生成 8 户布局（参数化），房子 tile 从原版 fz 层复制、树篱/路/装饰按布局表填
   - 同步扩 `zhujuejiaMapPlant` 的 plantSoils（新宅基地可种地）
   - 输出出生点表（每户门口坐标）
2. **服务器** `afserver.mjs`：
   - 出生点表按玩家序号分配 → 新玩家 `playerData.playerPos` = 自己宅基地门口
   - （玩家 0/1 = 原版中央院子不动）
3. **mod.js**：
   - 场景加载后（sceneType=1 家门口），按出生点表给每户房子的墙/树注入 BoxCollider（运行时创建节点挂场景层）
4. **验证**：新玩家进游戏出现在自己宅基地 → 截图视觉质检（风格一致性、无明显重复）→ 双窗口互访

## 四、已知取舍（P0）

- **室内**：所有玩家共用原版室内场景（进任何房子都进同一个"家室内"）；每户独立室内 = 场景实例化改造，放 P1+
- **过夜**：昼夜切换回原版中央房子室内（共享），早上从中央院子醒；宅基地 = 出生点+专属田地
- **门 passage**：新房子暂不可进屋（墙碰撞生效，进门触发 P1 加）

## 五、工作量

- 工具脚本（地图扩展+布局生成）：半天
- 服务器出生点分配：半小时
- mod.js 碰撞注入：半天
- 验证+视觉质检：半天
- 合计约 2 天
